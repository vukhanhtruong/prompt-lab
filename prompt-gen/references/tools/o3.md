# O3 / O4-mini / DeepSeek-R1 (Reasoning Models)

Type: Reasoning
Template: [rtf](references/templates/rtf.md) — use minimal variant only
Patterns: [reasoning](references/patterns/reasoning.md)

## Characteristics

- Reasons across thousands of internal tokens — NO external scaffolding needed
- CoT instructions actively DEGRADE output
- Short clean instructions work best
- Keep system prompts under 200 words

## Guidance

- SHORT clean instructions ONLY — state goal and done condition
- Prefer zero-shot first — add few-shot only if strictly needed and tightly aligned
- State what you want and what done looks like. Nothing more.
- Keep prompts minimal — longer prompts hurt performance

## Required Additions

None. Keep it minimal. These models think internally.

## Anti-patterns

- NEVER add "think step by step" or CoT scaffolding — it degrades output
- NEVER add chain-of-thought template — they reason internally
- NEVER use long system prompts — under 200 words
