# O3 / O4-mini (Reasoning Models)

Type: Reasoning
Template: [chain-of-thought](references/templates/chain-of-thought.md)
Patterns: [reasoning](references/patterns/reasoning.md)

## Characteristics

- Reasons across thousands of internal tokens
- CoT instructions actively degrade output
- Short clean instructions work best
- Keep system prompts under 200 words

## Guidance

- SHORT clean instructions ONLY
- State what you want and what done looks like. Nothing more.
- Prefer zero-shot first — add few-shot only if strictly needed
- Keep prompts minimal — longer prompts hurt performance

## Required Additions

None. Keep it minimal.

## Anti-patterns

- NEVER add "think step by step" or CoT scaffolding — it degrades output
- NEVER add reasoning instructions — they reason internally
- NEVER use long system prompts
