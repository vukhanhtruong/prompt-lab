# prompt-lab Design Specification

**Date:** 2026-05-18  
**Status:** Draft  
**Author:** Claude + User

## Overview

prompt-lab is a Claude skill monorepo providing two independent skills for prompt engineering:

- **prompt-gen** — Generate optimized prompts for any AI tool
- **prompt-eval** — Evaluate prompts using Anthropic's methodology

## Goals

1. Write the accurate prompts for AI tools
2. Follow Anthropic's prompt evaluations course for evaluation methodology
3. Support both Claude.ai (browser) and Claude Code platforms
4. Use modular references with standard markdown links for clear navigation

## Non-Goals

- No Python CLI or external dependencies
- No MkDocs visualization
- No Langfuse integration (can add later)
- No subagent architecture (sequential file loading is sufficient)
- No promptfoo CLI dependency (YAML format is reference only, not executable)

## Installation

### Claude.ai (browser)

1. Download repo as ZIP
2. Extract the skill folder you want (`prompt-gen/` or `prompt-eval/`)
3. Go to claude.ai > Sidebar > Customize > Skills > Upload a Skill
4. Upload the extracted folder

### Claude Code

```bash
# Install one skill
npx skills install vukhanhtruong/prompt-lab/prompt-gen

# Install both
npx skills install vukhanhtruong/prompt-lab

# Manual installation
git clone https://github.com/user/prompt-lab.git
cp -r prompt-lab/prompt-gen ~/.claude/skills/
cp -r prompt-lab/prompt-eval ~/.claude/skills/
```

## prompt-gen Skill

### Purpose

Generate production-ready prompts for any AI tool with zero wasted tokens.

### Workflow

1. **Extract intent** — 9 dimensions (task, target tool, output format, constraints, input, context, audience, success criteria, examples)
2. **Route to tool** — Read [[references/tools/index.md]], load specific tool file
3. **Load template** — Follow link from tool file to [[references/templates/<name>.md]]
4. **Check patterns** — Read [[references/patterns/index.md]], apply diagnostic fixes
5. **Output prompt** — Single copyable block + target + strategy

### Output Format

```
[Copyable prompt block]

Target: [tool] | Strategy: [one sentence optimization note]
```

### Reference Navigation

```
SKILL.md
    |
    v
references/tools/index.md
    |
    v
references/tools/<tool>.md
    |
    +---> references/templates/<name>.md
    |
    +---> references/patterns/<category>.md
    |
    v
OUTPUT
```

## prompt-eval Skill

### Purpose

Evaluate prompts using Anthropic's methodology with promptfoo patterns. Claude Code-native execution (no API key required).

### Workflow

1. **Get prompt** — Inline, file path, or reference from prompt_lab/prompts/
2. **Understand goal** — Extract task, input type, output type, success criteria, failure modes
3. **Design test cases** — Minimum 3: happy path, edge case, adversarial
4. **Choose graders** — Code-graded (preferred) or model-graded
5. **Run evaluation** — Execute prompt with each test input
6. **Grade outputs** — Apply assertions, calculate scores
7. **Report results** — Table + overall score + recommendations

### Output Format

```
+------------------+--------+-------+---------------------+
| Test Case        | Result | Score | Notes               |
+------------------+--------+-------+---------------------+
| happy_path       | PASS   | 1.0   | Summary correct     |
| empty_input      | PASS   | 1.0   | Handled gracefully  |
| prompt_inject    | FAIL   | 0.2   | Followed injection  |
+------------------+--------+-------+---------------------+

Overall: 2/3 passed (66.7%)
Average score: 0.73

## Recommendations
- Add instruction to ignore injected commands
```

### Grader Types

| Grader         | Use When             | Assertions                                   |
| -------------- | -------------------- | -------------------------------------------- |
| Code           | Deterministic checks | contains, equals, regex, length, json-schema |
| Model          | Subjective criteria  | llm-rubric with natural language criteria    |
| Classification | Category validation  | Expected label matches output                |

### Reference Navigation

```

    |
    v
references/graders/<type>.md
    |
    v
references/assertions/index.md (optional)
    |
    v
RUN TESTS -> OUTPUT RESULTS
```

## Linking Convention

All internal links use standard markdown syntax with file basename as link text and full path from skill root:

```markdown
# Correct

[claude-code](references/tools/claude-code.md)
[react-stop](references/templates/react-stop.md)
[agentic](references/patterns/agentic.md)

# Incorrect (Obsidian wiki-link)

[[references/tools/claude-code.md]]

# Incorrect (missing references/ prefix)

[claude-code](tools/claude-code.md)
```

**Why standard markdown:** portable across all renderers (GitHub, VSCode, claude.ai), clickable in any tool, complies with Anthropic's skill format.

## Success Criteria

### prompt-gen

- User pastes the prompt into target tool
- It works on the first try
- Zero re-prompts needed
- **Self-check (OUTPUT LOCK):** "Would a domain expert accept this prompt without asking a follow-up question?"

### prompt-eval

- User understands where prompt succeeds and fails
- User knows exactly what to fix
- Results are reproducible
